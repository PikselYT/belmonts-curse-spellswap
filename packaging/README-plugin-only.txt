SPELL SWAP (plugin only) for Castlevania: Belmont's Curse
==========================================================

This package contains ONLY the plugin. It needs BepInEx 6 (IL2CPP) bleeding-edge build 789 or newer
already installed in the game. If you do not have BepInEx and want the easy way, download the other
package from the release page ("SpellSwap-<version>.zip" - it installs everything for you).

INSTALL
  1. Close the game.
  2. Extract this zip INTO THE GAME FOLDER (the folder that contains "Castlevania Belmont's Curse.exe").
     The file ends up at:  BepInEx\plugins\SpellSwap\SpellSwap.dll
  3. Start the game. Controller D-pad LEFT / RIGHT now switches spells; the left stick walks.

UNINSTALL
  Delete the folder  BepInEx\plugins\SpellSwap

Log file if something does not work:  <game folder>\BepInEx\LogOutput.log
Project page: https://github.com/PikselYT/belmonts-curse-spellswap
