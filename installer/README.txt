SPELL SWAP for Castlevania: Belmont's Curse
===========================================

Controller D-pad LEFT / RIGHT switches your spell. The left stick walks (the D-pad no longer walks).

INSTALL (30 seconds)
  1. Close the game.
  2. Double-click  Install.bat   (if Windows shows a blue "protected your PC" box:
     click "More info" -> "Run anyway").
  3. Start the game from Steam. The FIRST start takes 1-3 minutes (the screen can look frozen).
     That is BepInEx preparing itself - later starts are normal.

UNINSTALL
  Double-click  Uninstall.bat

If something does not work, see the log:  <game folder>\BepInEx\LogOutput.log
More help: https://github.com/PikselYT/belmonts-curse-spellswap
